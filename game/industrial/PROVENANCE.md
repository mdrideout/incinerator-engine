# Industrial demo world

External source material: none

Original geometry and procedural textures authored for Incinerator Engine.
`generate.py` owns the geometry, texture recipes, and matching building collision.
All dimensions are in metres. `materials.icmat` owns the authored material values
and mesh assignments. Regeneration preserves existing materials and bindings,
adding entries only for newly authored material identities.

The vehicle test road extends south through sixteen streamed 64 m districts.
It has a 24 m asphalt width, paved runoff and distance-marker blocks whose
visible dimensions match collision. The original neighborhood is retained.
